# land_registry_sim

조선 양안 / 오스만 타흐리르 데프테리 / 중국 어린도책, 세 가지 전근대 토지대장
기록 방식을 "기록형태(구조화 정도)" 관점에서 비교·재현하는 시뮬레이션.

## 실행 방법 (VSCode)
1. 이 폴더를 VSCode로 열기
2. `pip install matplotlib` (설치 안 돼 있다면)
3. `python main.py` 실행 → 콘솔에 전 과정 출력 + outputs 폴더에 시각화 이미지 생성

## 파일 구성
- `data_generator.py`   : 가상 마을 필지 데이터 생성 (단일 소스, 세 포맷이 공유)
- `format_yangan.py`    : 양안식 - 순수 텍스트 서술 + 문자열/정규식 검색
- `format_defteri.py`   : 데프테리식 - 표(딕셔너리) 구조 + 필드 기반 검색·집계
- `format_eorindochaek.py` : 어린도책식 - 표+좌표 구조 + 공간 질의
- `benchmark.py`        : 세 방식에 동일 질의를 던져 실행시간·지원여부 비교
- `visualize.py`        : 어린도책 스타일 시각화 (matplotlib, 등급별 색상)
- `main.py`             : 전체 파이프라인 실행 진입점

## 주의사항 (자평서 작성 시 반드시 명시)
- 여기 쓰인 필지 데이터는 실제 조선/오스만/중국 사료의 정밀 수치가 아니라
  세 기록 방식의 구조적 차이를 비교하기 위해 만든 가상 예시 데이터임.
- 실행시간 비교는 "구조화 정도에 따라 같은 질문을 처리하는 코드의 형태와
  가능 여부가 달라진다"는 것을 보여주기 위함이며, 이 규모(수백 개 필지)에서
  절대적인 속도 차이 자체를 실용적 성능 지표로 확대 해석하지 않을 것.
